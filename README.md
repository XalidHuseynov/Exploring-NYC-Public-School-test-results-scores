# Exploring-NYC-Public-School-test-results-scores


Проект по исследованию результатов стандартизированных тестов (SAT) в государственных школах Нью-Йорка (NYC) с использованием библиотеки **Pandas**. 

В данном исследовании анализируются результаты учащихся по трем направлениям (математика, чтение, письмо) для выявления сильнейших школ города и анализа разброса результатов по районам (boroughs).

---

## 📌 Основные задачи и результаты

### 1. Лучшие школы по математике (Best Math Results)
Фильтрация школ, где средний балл по математике не менее 640 из 800 возможных.
* **Лидер:** *Stuyvesant High School* со средним баллом **754** по математике.
* В топ также вошли *Bronx High School of Science* (714) и *Staten Island Technical High School* (711).

### 2. Топ-10 школ по суммарному баллу SAT (Combined SAT Scores)
Создание колонки `total_SAT` (сумма баллов по математике, чтению и письму) и определение 10 лучших учебных заведений города.
* **1 место:** *Stuyvesant High School* — суммарный балл **2144** из 2400.
* В первой тройке: *Bronx High School of Science* (**2041**) и *Staten Island Technical High School* (**2041**).

### 3. Район с наибольшей вариативностью результатов (Largest Standard Deviation)
Анализ стандартного отклонения суммарного балла SAT в разрезе боро (районов) Нью-Йорка.
* **Район с наибольшим разбросом:** **Manhattan**
* **Количество школ в районе:** 89
* **Средний суммарный балл (`average_SAT`):** 1340.13
* **Стандартное отклонение (`std_SAT`):** 230.29
